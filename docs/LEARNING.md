Newest entries at the bottom. Two entry types:

```
## YYYY-MM-DD: Slice N: <name>
- What the code does, in my words
- Python/Flask ideas used
- What I got wrong in the review quiz, and the right answer

## YYYY-MM-DD: <what broke>
- Symptom: what I saw (error text, command output)
- Cause: why it happened
- Fix: what I changed
- Lesson: what I'd check first next time
```
