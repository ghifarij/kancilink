# Incidents

Each incident is a failure I cause on purpose, observe, and recover from. For each one I write two files myself:

- `NN-name-runbook.md`: how to detect it, diagnose it and recover, step by step.
- `NN-name-postmortem.md`: timeline, impact, root cause, what worked, what I'd change.
